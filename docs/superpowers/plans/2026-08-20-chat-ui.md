# План реализации: чат в веб-интерфейсе

> **Для агентов:** ОБЯЗАТЕЛЬНЫЙ ПОДНАВЫК — используйте
> superpowers:subagent-driven-development (рекомендуется) либо
> superpowers:executing-plans, чтобы выполнять план задача за задачей.
> Шаги размечены чекбоксами (`- [ ]`) для отслеживания.

**Цель:** пользователь ведёт переписку в браузере — ответ печатается потоком,
диалоги сохраняются, между ними можно переключаться и удалять их.

**Архитектура:** `/ask/stream` переходит с `text/plain` на NDJSON, потому что
источники известны только после генерации; обработчик накапливает поток
и после его завершения пишет обе реплики в историю, как это делает `/ask`.
Разметка переезжает из `api.py` в новый модуль `ragkb/ui.py` и получает список
диалогов рядом с перепиской.

**Технологии:** Python 3.10+, FastAPI, ванильный JavaScript без сборки.
Новых зависимостей не добавляется.

**Спека:** `docs/superpowers/specs/2026-08-20-chat-ui-design.md`

**Предшествующая работа:** части 1 и 2 в `main`. Доступны `ragkb/auth.py`
с `User` и `current_user`; `ragkb/history.py` с `HistoryStore` и `make_title`;
эндпоинты `/conversations` с пагинацией; `/ask` с `conversation_id`.

## Общие ограничения

- **Новых зависимостей в `pyproject.toml` не добавлять.** Разметка — ванильный
  JavaScript, без сборки и без внешних библиотек.
- **Поток отдаёт NDJSON**, media type `application/x-ndjson`: по одному объекту
  JSON на строку. События: `{"type":"token","text":"..."}`,
  `{"type":"done","conversation_id":...,"sources":[...],"warnings":[...],"elapsed_sec":...}`,
  `{"type":"error","detail":"..."}`.
- **Ошибка после первого байта выражается событием `error`, а не кодом ответа.**
  Статус уже отправлен и равен 200, сменить его невозможно.
- **Диалог создаётся только после успешной генерации** — как в `/ask`. Иначе
  при обрыве остаётся запись с заголовком без сообщений, которую пользователь
  не может ни продолжить, ни удалить.
- **Отказ записи в историю не роняет уже отданный ответ** — попадает
  в `warnings` события `done`.
- **Чужой и несуществующий диалог неотличимы по ответу** — оба 404, до начала
  потока.
- **Фильтрация владельца живёт в SQL** — обеспечивается методами `HistoryStore`,
  поверх них ничего фильтровать не надо.
- **Стриминг есть только у Ollama.** `LLM.stream` переопределён в `llm.py:83`
  только у `OllamaLLM`; базовая реализация (`llm.py:27`) отдаёт весь ответ
  одним куском, её наследуют `OpenAILLM` и `ExtractiveLLM`. Интерфейс обязан
  работать одинаково и не рассчитывать на постепенность.
- **Тесты запускаются без pytest.** Файл исполняется как
  `python tests/test_stream.py`; в конце файла раннер, перебирающий `globals()`.
  Тестовые функции без обязательных аргументов. Образцы —
  `tests/test_history.py`, `tests/test_auth.py`, `tests/test_pipeline.py`.
- **Язык кода, комментариев и документации — русский.**
- **Коммит после каждой задачи.**

**Разметка автоматическими тестами не покрывается** — в проекте нет браузерного
окружения, и заводить его ради одной страницы несоразмерно. Это записано
в спеке как риск. Проверка интерфейса ручная, по сценарию из задачи 4.

**Механика проверена заранее** на этом окружении, чтобы исполнитель не выяснял
её вслепую: метод, в теле которого нет `yield`, выполняется сразу и возвращает
кортеж, а вложенный генератор остаётся ленивым; `TestClient` собирает тело
`StreamingResponse` целиком и отдаёт его через `.text`, поэтому поток
разбирается в тестах построчно; `json.dumps(..., ensure_ascii=False)` не портит
кириллицу; в тройной строке Python последовательность `\\n` даёт в исходнике
JavaScript двухсимвольный литерал `\n`, а `\n` дала бы настоящий перевод строки
и порвала бы строковый литерал.

```python
    def stream_answer(
        self,
        question: str,
        *,
        top_k: int | None = None,
        history: list[tuple[str, str]] | None = None,
    ) -> tuple[list[Hit], Iterator[str]]:
        """Готовит поток ответа и отдаёт найденные фрагменты сразу.

        Кортеж, а не генератор, по одной причине: источники вычисляются
        по готовому тексту через _cited_sources, но список Hit нужен
        вызывающему коду раньше — до того, как поток закончится. Генератор
        отдать его не может, не смешивая типы событий в одном потоке.

        Пустой список фрагментов означает, что поиск ничего не дал.
        """
        search_query = question
        if history:
            search_query = self._condense(question, history) or question

        hits = self.search(search_query, top_k=top_k)
        if not hits:
            def nothing_found() -> Iterator[str]:
                yield "В базе знаний нет информации по этому вопросу."

            return [], nothing_found()

        prompt = ANSWER_TEMPLATE.format(context=format_context(hits), question=question)
        return hits, self.llm.stream(SYSTEM_PROMPT, prompt)
```

Обрати внимание: тело метода больше не содержит `yield`, поэтому вызов
выполняется сразу и возвращает кортеж. Сам поток остаётся ленивым — ошибка
обращения к модели вылезет на первой итерации, а не при вызове.

```python
    @app.post("/ask/stream")
    def ask_stream(req: AskRequest, user: User = Depends(current_user)) -> StreamingResponse:
        store = history_store
        conversation_id = req.conversation_id
        turns: list[tuple[str, str]] | None = [tuple(h) for h in req.history] or None

        if store is not None:
            store.cleanup()
            if conversation_id:
                if not store.owns(conversation_id, user.name):
                    # Чужой и несуществующий неотличимы по ответу.
                    raise HTTPException(status_code=404, detail="Диалог не найден")
                turns = store.recent_turns(
                    conversation_id, user.name, cfg.history.window
                ) or turns

        # Поиск и подготовка потока выполняются здесь, до отдачи первого байта:
        # пока статус ответа не отправлен, об отказе ещё можно сообщить кодом.
        started = time.time()
        rag = pipeline()
        hits, tokens = rag.stream_answer(req.question, top_k=req.top_k, history=turns)

        def generate() -> Iterator[str]:
            nonlocal conversation_id
            collected: list[str] = []
            try:
                for piece in tokens:
                    collected.append(piece)
                    yield json.dumps(
                        {"type": "token", "text": piece}, ensure_ascii=False
                    ) + "\n"
            except Exception as exc:
                # Статус уже отправлен и равен 200 — сменить его нельзя,
                # поэтому об отказе сообщаем событием. Молчаливый обрыв
                # потока выглядел бы для пользователя зависшим ответом.
                yield json.dumps(
                    {"type": "error", "detail": str(exc)}, ensure_ascii=False
                ) + "\n"
                return

            text = "".join(collected)
            # Считаем один раз: то же самое уходит и в историю, и в событие done.
            sources = RAGPipeline._cited_sources(text, hits)
            warnings: list[str] = []

            if store is not None:
                # Диалог заводим только после успешной генерации — как в /ask.
                if not conversation_id:
                    conversation_id = store.create_conversation(
                        user.name, make_title(req.question)
                    )
                # Ответ уже отдан пользователю, отказ записи не должен его портить.
                try:
                    saved_question = store.append(
                        conversation_id, user.name, "user", req.question
                    )
                    saved_answer = store.append(
                        conversation_id, user.name, "assistant", text, sources
                    )
                    if not (saved_question and saved_answer):
                        warnings.append("Ответ не сохранён в историю диалога")
                except Exception:
                    warnings.append("Ответ не сохранён в историю диалога")

            yield json.dumps(
                {
                    "type": "done",
                    "conversation_id": conversation_id,
                    "sources": sources,
                    "warnings": warnings,
                    "elapsed_sec": round(time.time() - started, 2),
                },
                ensure_ascii=False,
            ) + "\n"

        return StreamingResponse(
            generate(), media_type="application/x-ndjson; charset=utf-8"
        )
```
