# Приложение без аккаунтов и истории

## Требование

Пользователь подтвердил удаление авторизации, логинов, паролей, пользователей,
ролей, создания администратора и истории диалогов. Сайт открывает чат сразу.
Управление документами и индексацией доступно каждому посетителю.

## Поведение

- Текущие вопросы и ответы отображаются только в памяти открытой страницы.
  Обновление страницы или кнопка «Очистить чат» удаляют их из интерфейса.
- Каждый вопрос независим: предыдущие сообщения не сохраняются на сервере
  и не передаются модели как история. Нет общего диалога для посетителей.
- Поток ответа, выбор модели, ссылки на источники и копирование остаются.
  Повтор ответа выполняется новым запросом с тем же вопросом.
- Удаляются страницы входа, регистрации, профиля, пользователей, список
  диалогов и операции над сохранёнными сообщениями.
- Оценки ответов и сводка оценок удаляются вместе с историей: сейчас они
  привязаны к сохранённым сообщениям. Новое независимое хранение оценок
  в эту задачу не входит.

## Backend и BFF

Новый POST /api/v1/ask принимает question, model, top_k, expand, без
пользователя, организации или идентификатора диалога. Сохраняется NDJSON:
события token и завершающее done с источниками, предупреждениями, моделью,
временем и признаком truncated. Ошибки до начала потока возвращаются как
HTTP-ошибки; сбои генерации обрабатываются с существующим экстрактивным
резервным ответом либо признаком обрыва после полученных токенов.

Сценарий ответа использует AnswerEngine и каталог моделей через порты,
без репозиториев истории. Старые API аккаунтов, сессий, пользователей,
диалогов и оценок удаляются. Bootstrap возвращает сведения о приложении,
организации, моделях и индексе, без пользователя и диалогов.

С остальных маршрутов снимаются зависимости аутентификации и проверки
администратора. BFF остаётся единственным каналом браузера к FastAPI;
из него удаляется передача идентификационных заголовков и сессионных cookie.
Телеметрия не содержит личности пользователя и текста переписки.

## Документы и база данных

Реестр corpus_documents, документы и индекс сохраняются. При подключённой
БД индекс по-прежнему строится только по принятым документам. Без БД остаётся
существующее поведение с предупреждением об индексации каталога целиком.
Новые документы не получают идентификатор загрузившего пользователя.

Рабочие модели, порты и репозитории аккаунтов, сессий, диалогов, сообщений
и оценок удаляются из приложения. Исторические миграции сохраняются для
совместимости существующей цепочки Alembic; миграционный env больше не
зависит от UserRow. Имеющиеся таблицы с аккаунтами и перепиской не читаются
и не заполняются. Автоматическое физическое уничтожение старых данных не
входит в эту переделку: обновление приложения не должно стирать существующую БД.

## Запуск и документация

Удаляются ensure-admin, ADMIN_LOGIN, ADMIN_PASSWORD, режимы авторизации,
параметры истории, связанные зависимости и команды Compose/deploy.
Postgres и миграции остаются для реестра документов. Обновляются README,
AGENTS.md и примеры окружения; исторические планы не переписываются.

## Проверка результата

- Без cookie открываются чат, документы и управление индексом.
- Старые API аккаунтов, пользователей и диалогов отсутствуют.
- Ответы и источники работают через BFF; неизвестная модель и пустой
  вопрос отклоняются; обрыв генерации корректно завершает поток.
- Два запроса независимы и не создают записей переписки; перезагрузка
  страницы очищает сообщения.
- Загрузка, принятие, удаление документов и перестроение индекса сохраняют
  семантику реестра.
- Тесты удалённых сценариев заменяются проверками нового контракта;
  выполняются backend pytest, frontend check/build и проверка Compose.

## Статус

Реализовано на ветке `codex/remove-auth-history`. Авторизация, аккаунты, роли,
история диалогов и оценки удалены; сайт открывает чат сразу, каждый вопрос
независим, сервер не хранит переписку даже в памяти.

Проверено: `pytest` в backend, `bun test` / `bun run check` / `bun run build`
в frontend, а также локальный прогон через BFF — health, bootstrap, поток
ответа, документы; удалённые маршруты и страницы отвечают 404. Существующие
таблицы аккаунтов и переписки в БД не тронуты, исторические миграции сохранены.
